Looking for a satellite to play chess with.

Forgotten machines still circle the Earth, and a few of them carried a computer built to take software from the ground. This is a map of them, a receive-only station, and a board with nobody on the other side yet.

how it would work the satellite's move arrives in the ordinary downlink as a small file (MOVE####, four bytes, long algebraic: c7c5) — PACSAT broadcast, AX.25 UI frames, decoded with gr-satellites → KISS → file assembler. Nothing new on the RF side.

    
the other direction needs the operator's yes. That is the part of the project that takes the longest, and nothing gets transmitted before it.

    
chess.bin 6.3 kB · no graphics, no networking, no opening book · one move in, one move out · runs on the V40 emulator with 200 kB and a slow clock

  






  

    
Candidates

    
Old birds with an onboard computer that was, at some point, meant to accept software from the ground. Ranked by how much of the machine is demonstrably still there. Ranking is an opinion; the identifiers are not.
